    FIELD GUIDE / KNOW THE BOUNDARY
    
        
    Understand the alert before acting.
    
        
    
          
    
            Start with a controlled surprise
            
    
              Run isolated spike, inspect tick120 and the thermal channel, then compare with slow
              drift or stuck sensor. Select the bus channel for partial dropout: absent readings are
              marked missing, never healthy zeros. Changing configuration requires Analyze
              telemetry; downloads always belong to the last completed run.
            
    
          
    
          
    
            What the rules mean
            
    
              Point-limit flags a residual beyond the chosen median/MAD band. Drift uses causal EWMA
              with weight0.2 and threshold0.6 times the limit multiplier. Flatline requires six
              exactly equal consecutive readings in one context. These are explainable heuristics,
              not a trained neural network or failure diagnosis.
            
    
          
    
          
    
            Analyze a local CSV
            
    
              Download Input CSV for the strict schema. The CLI accepts only UTF-8 CSV with
              tick,mode,thermal,bus,load columns,240 or480 ordered rows and bounded finite numeric
              values; blanks mean missing. Use export --input file.csv --output report.json. Labels
              are unknown for imports, so accuracy metrics stay undefined. No browser upload
              endpoint exists.
            
    
          
    
          
    
            Privacy, limits & support
            
    
              No analytics, accounts, advertisements or external AI calls. Only finite preferences
              use optional browser storage. Data cannot control a spacecraft. Desktop bundles run
              locally; they are unsigned. Do not disable OS protections. Read the repository docs or
              contact the author for help.
